# Linked RDA data in practice
[[Sarah Hartmann]], [[Alexander Haffner]]

The new “[[Resource Description and Access]]” ([[RDA]]) indexing standard allows [[bibliographic data]] and [[authority data]] to be represented in a Semantic Web-compliant manner. The presentation aims to show the effects RDA has on cataloging in libraries and access to the resources in the Semantic Web. Based on initial experiences from practical implementation, it is explained how [[bibliographic data]] can be made more accessible and, above all, reused through RDA and linked data technologies.
