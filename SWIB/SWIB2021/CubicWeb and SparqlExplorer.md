# CubicWeb and SparqlExplorer

Chat channel: https://swib21.collochat.de/swib21/channels/cubicweb–sparqlexplorer
URL: https://forge.extranet.logilab.fr/cubicweb/cubicweb &amp; https://forge.extranet.logilab.fr/open-source/SemWeb/sparqlexplorer

Description: CubicWeb is a semantic web application framework, licensed under the LGPL, that empowers developers to efficiently build web applications and manage data. It can create an application based on an OWL ontology and import RDF described with this ontology (see also the CubicWeb workshop on Tuesday, 14:00 UTC). With SparqlExplorer, we can visually explore the content of a [[SPARQL]] endpoint without writing queries (see also the SparqlExplorer talk on Wednesday, 15:30 UTC).
CubicWeb &amp; SparqlExplorer are both maintained by LogiLab.
