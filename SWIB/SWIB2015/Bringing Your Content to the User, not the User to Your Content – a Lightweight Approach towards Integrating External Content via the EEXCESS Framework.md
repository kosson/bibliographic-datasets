# Bringing Your Content to the User, not the User to Your Content – a Lightweight Approach towards Integrating External Content via the EEXCESS Framework
[[Werner Bailer]], [[Martin Höffernig]]

This workshop will look at the steps and tools needed to adapt scientific and cultural heritage assets to services which make them available to wide community of users on the platforms they already use, e.g., as a plugin in their web browser or on their blogging environment. The [[EEXCESS]] project has developed such a service, and welcomes GLAM institutions to make their data available.
Data providers face two basic problems:
- Provision of their data in various formats in order to match available services.
- Quality issues while mapping their specific data to other formats.
On this background, in the EU funded project EEXCESS a tool chain has been developed to make data provision as simple as possible for the providers. Many of these tools are also useful in other contexts, e.g., data provision to local/thematic cultural heritage portals or to Europeana. The workshop will provide an introduction to the data provision process and will then guide participants to each of the following steps, allowing them to play hands-on with the tools provided:
• Creating data format mappings: Using a web-based graphical user interface, we will define mappings from the provider’s source metadata format to a common format used in the service, such as the Europeana Data Model ([[EDM]]). The creation of the mappings is an iterative process that comprises testing the created mappings and refining the mapping.
• Quality assessment: Using tools for getting metrics about the completeness and reusability of the source metadata, as well as using mapping quality metrics to get feedback for improving the defined mapping.
• Mapping controlled vocabularies (e.g., thesauri): Publishing metadata may require linking in-house controlled vocabularies or at least single concepts with publicly accessible and more interoperable vocabularies, such as those published in the LOD cloud.
• Semantic enrichment: Using LOD to enrich the metadata, thus facilitating linking with other content and increasing visibility and access.
• Participants are invited to make their own data available for use in the workshop, either by providing a description of an API of their organization, or by providing at least parts of their metadata in a machine readable format.
