# Standardizing Changes to Entity Datasets
[[Simeon Warner]], [[Steven Folsom]]

The <a href="https://ld4.github.io/entity_metadata_management/0.1/">Entity Metadata Management API (EMM API)</a> is an effort with the LD4 community to define a specification for communicating changes to linked data entity datasets so that data consumers are aware of new, updated, and deprecated entities as the dataset evolves over time. Understanding these types of changes are critical for a number of use cases including local caching of labels and caching of full datasets. Simeon Warner and Steven Folsom will provide an introduction to the preliminary specification and facilitate a discussion to gather initial reactions and capture use case for possible future versions of the API.
