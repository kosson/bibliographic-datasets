# Creating linked open usable data with Metafacture
[[Pascal Christoph]], [[Tobias Bülte]]

Metafacture is a powerful free and open source ETL tool. We will learn how to transform bibliographic data from MARC21 to JSON-LD (see <a href="http://lobid.org/resources/99372425395706441.json">link</a> as an example of a result of the ETL from Alma’s MARC21 to lobid’s JSON-LD). Best practices are shown of how to sensibly do that, i.e. by defining a context and by creating URIs instead of strings for identifiers (IDs). We will enrich our records with SKOS data to gain valuable IDs and Strings. No installation is required – all you need is a browser.
