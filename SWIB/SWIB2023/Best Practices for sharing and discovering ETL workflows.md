# Best Practices for sharing and discovering ETL workflows
[[Tobias Bülte]]

Many libraries do some kind of metadata transformation e.g. for indexing different data sources in a discovery service or for migrating to another LMS. However, usually ETL (extract, transform, load) workflows are not being shared between libraries let alone being discoverable for a wider community. In this session we want to discuss best practices to foster sharing and reuse of ETL workflows by discussing the following questions: What are use cased for finding and reusing ETL processes? How would people like to discover existing workflows? What core information helps discoverability and how should it be provided?
